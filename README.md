# DIKWP-MESH 9.0 Internal Responsibility Runtime

A generic, case-independent runtime that compiles user intent, typed relations, active decisions, substantive protection, audience disclosure, authority, execution, world effect, acceptance and correction into one replayable responsibility worldline.

## Quick start

```bash
python mesh90.py summary
python mesh90.py conformance
python mesh90.py demo-all --out-dir outputs/demos
python mesh90.py run examples/full_closure.mesh90.json --out outputs/full.run.json --dashboard dashboard/full.html
python mesh90.py public-bridge outputs/full.run.json --out outputs/full.public.json
```

## Critical relation boundary

Affiliation != adoption; coauthorship != organizational deployment; event/media/evaluation != use; structural similarity != provenance or authorization.

This package contains no person-specific case dataset.
